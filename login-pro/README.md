# Login/Signup App (Pro)

**Author:** Divya Sabale

A modern responsive login/signup front-end project built with HTML, CSS, and JavaScript.

## Features
- Login and Signup pages with form validation.
- Password strength indicator and show/hide toggle.
- Dark mode switch.
- Responsive layout with smooth transitions.

## How to use
1. Unzip the folder.
2. Open `index.html` in any modern browser.
3. Test login (demo only).
4. Navigate to signup and test features.
